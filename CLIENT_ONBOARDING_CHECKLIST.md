# Client Onboarding Checklist

> **Use for every new client. Duplicate this file per client.**

---

## Pre-Sale (During Demo)

- [ ] Demo booked on Calendly
- [ ] 15-min demo completed (show widget live, configure 3 rules)
- [ ] Proposal sent (PDF with pricing, scope, 30-day free trial terms)
- [ ] Proposal signed / verbal agreement
- [ ] Setup fee invoiced (Starter: $299, Pro: $599, Business: $999)

---

## Week 1: Setup & Go-Live

### Day 1-2: Technical Setup
- [ ] Create Tawk.to property (in your agency account or client's)
- [ ] Configure widget appearance (colors, position, greeting)
- [ ] Add pre-chat form fields (name, phone, address, service, urgency)
- [ ] Create 10 HVAC shortcuts (copy from `APPROACH_A_TAWKTO_SETUP.md`, customize)
- [ ] Add 5 Knowledge Base articles (customize for client)
- [ ] Set up departments: Vendas, Suporte, Agendamento
- [ ] Configure notifications (email + mobile push)

### Day 2-3: Automation
- [ ] Duplicate Make scenario template
- [ ] Update client WhatsApp number in scenario
- [ ] Update client email in scenario
- [ ] Create client row in Google Sheets "Clients" tab
- [ ] Test: Run 3 test chats → verify WhatsApp + Email + Sheets
- [ ] Fix any formatting issues

### Day 3-4: Client Training (30 min call)
- [ ] Screen share: Show Tawk.to dashboard
- [ ] Show: How to see live chats, respond, tag, transfer
- [ ] Show: How to edit shortcuts (give them cheat sheet)
- [ ] Show: Mobile app setup + push notifications
- [ ] Show: Weekly report access (Google Sheets link)
- [ ] Send: Lead cheat sheet PDF + shortcut reference card

### Day 4-5: Go-Live
- [ ] Add widget code to client's website (or send to their dev)
- [ ] Verify widget loads on all pages (mobile + desktop)
- [ ] Test live: You chat as visitor → lead arrives on their WhatsApp
- [ ] Client confirms: "Lead received, format looks good"
- [ ] **GO LIVE** 🎉

---

## Week 2: Optimization

- [ ] Day 8: Check-in call (15 min) - "How many leads? Quality?"
- [ ] Adjust shortcuts based on real questions
- [ ] Add 3-5 new Knowledge Base articles from real chats
- [ ] Tune pre-chat form (add/remove fields)
- [ ] Set up "qualified" tag workflow if not done

---

## Week 3: First Results Review

- [ ] Pull Week 1-2 metrics from Google Sheets
- [ ] Calculate: Leads total, Qualified %, Emergency %, By service
- [ ] Send weekly report to client (template in `AUTOMATION_SETUP.md`)
- [ ] Ask: "Any leads turn into jobs?" (track revenue attribution)
- [ ] **Ask for referral** - "Know another HVAC owner who needs this?"

---

## Week 4: Trial Decision

- [ ] Day 25: Send trial summary report
- [ ] Day 27: Call - "Trial ends in 3 days. Results: X leads, Y jobs, $Z revenue"
- [ ] Day 28: If happy → Convert to paid (invoice first month)
- [ ] If not happy → Extend trial 15 days OR part ways (no hard feelings)

---

## Ongoing Monthly (After Paid)

### Weekly (Monday)
- [ ] Check Google Sheets for lead volume
- [ ] Spot-check 2-3 chat transcripts for quality
- [ ] Reply to any "needs human" escalations in Tawk.to

### Monthly (1st of month)
- [ ] Generate monthly report
- [ ] Invoice next month (Stripe/PayPal/TransferWise)
- [ ] Call: "How was last month? Any rule changes needed?"
- [ ] Update shortcuts/KB based on seasonal needs

### Quarterly
- [ ] Review pricing (upsell to Professional/Business?)
- [ ] Ask for testimonial/case study
- [ ] Ask for 2 referrals
