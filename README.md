# Nexora AI - Landing Page

Standalone landing page for **Nexora AI** — a 24/7 chatbot service for Canadian HVAC and home services companies.

Originally created on Polsia AI, recreated as a free, self-hosted static site.

## 🚀 Live Demo

Deploy to any static host in minutes:
- **GitHub Pages**: `https://usuario.github.io/nexora-ai/`
- **Netlify**: Drag & drop the folder
- **Vercel**: `vercel` CLI
- **Cloudflare Pages**: Connect Git repo

See [DEPLOY.md](DEPLOY.md) for detailed instructions.

## ✨ Features

- **Responsive** — Mobile-first, works on all devices
- **Accessible** — WCAG AA contrast, keyboard nav, ARIA labels
- **Fast** — Pure HTML/CSS/JS, no build step, no dependencies
- **Modern** — CSS custom properties, IntersectionObserver animations
- **Free to host** — No Polsia tokens, no monthly fees

## 🎨 Sections

1. **Hero** — Value prop + interactive chat preview
2. **Como funciona** — 3-step process (Receber → Entender → Continuar)
3. **Recursos** — FAQs, Captura de pedidos, Regras da operação
4. **Planos** — Starter ($299), Professional ($699), Business ($1,499) CAD/mês
5. **Disponibilidade** — What's ready vs coming soon (Voice, SMS, CRM)
6. **CTA** — Demo request via mailto

## 🛠 Customization

Edit `index.html` to update:
- Company name / branding
- Email addresses (`demo@nexora.ai`, `contato@nexora.ai`)
- Pricing (CAD/month + setup fees)
- Features & limitations
- Colors (via CSS custom properties in `styles.css`)
